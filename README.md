### 👋 About

I work across the entire stack — web, mobile, backend, and infrastructure — and I like building things **properly**: solid foundations over quick hacks, systems that stay easy to reason about long after they ship.

- 🛠️ &nbsp;Building products end to end, from schema and API to the apps people actually touch
- 🏗️ &nbsp;Care deeply about clean architecture, modular design, and long-term maintainability
- ⚡ &nbsp;Drawn to reliability, latency, and low-level systems — concurrency, networking, data
- 📚 &nbsp;Always learning something new and going deep on the fundamentals
- 💬 &nbsp;Happy to talk shop about architecture, design, and developer experience
